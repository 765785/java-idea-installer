安装过程

只需要三步

  1. 01

    下载并双击

    下载单个 BAT 文件，双击后开始安装。

  2. 02

    选择安装盘

    脚本列出可用磁盘，只选择一次目标盘符。

  3. 03

    等待并打开 IDEA

    自动下载安装、配置环境并创建桌面快捷方式。

安装内容

安装器会做什么

最新 JDK 25 LTS

从 Eclipse Adoptium 官方接口获取最新 JDK 25 补丁版，并校验 SHA-256。

固定版 IntelliJ IDEA

安装 Community 2025.2.6.2，不自动升级，避免开发环境意外变化。

桌面快捷方式

安装完成后在桌面创建 IDEA 快捷方式，并自动打开一次。

运行前确认

  • 浏览器下载后需要手动双击一次 BAT，浏览器不能直接运行本机程序。
  • Java 是标准 MSI 安装，可能会触发一次管理员权限确认。
  • 安装位置只会在所选盘中，不会遍历或修改项目源码。
  • 卸载 Java 和 IDEA 可直接使用 Windows“已安装的应用”。
